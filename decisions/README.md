# Decision Documents

This directory stores architecture and approach decision records.

## Rules

- All decision documents must be Markdown files in this directory.
- Use one decision per file.
- Prefer clear snake_case names ending in _decision.md.

Examples:

- sequence_rendering_backend_decision.md
- midi_export_event_model_decision.md

## Typical Contents

- Problem statement
- Importance and urgency
- Options considered (including do nothing)
- Recommendation
- Follow-up plan link (when implementation should proceed)
